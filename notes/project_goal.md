# MoPRM Project Goal

## Current Goal

Build and evaluate **MoPRM: a router-guided mixture of heterogeneous process reward models** for multi-domain reasoning.

The project should test whether a lightweight gate can route each problem, or later each problem-candidate pair, to the most suitable PRM/reward experts and improve Best-of-N candidate selection.

## Key Design Decision

The main expert pool must include at least **two non-OpenAI PRM/reward experts**.

The OpenAI-based scorer that produces math, logic, general, and reflective rubric scores is useful, but it is only an **OpenAI multi-rubric judge baseline**. It is not enough to support the final MoPRM claim because the four dimensions are generated by the same underlying model family and scoring interface.

## Target Expert Pool

| Expert | Source type | Role |
|---|---|---|
| `open_math_prm` | non-OpenAI open-source PRM | math process correctness |
| `open_reasoning_rm` | non-OpenAI open-source RM | response-level logic and general reasoning quality |
| `openai_general_judge` | OpenAI judge | broad candidate reliability |
| `openai_reflective_judge` | OpenAI judge | self-checking and error-recovery quality |

## Current Stage

The OpenAI-only baseline pipeline is complete at pilot scale:

```text
candidate generation
evaluation-only correctness labeling
OpenAI multi-rubric expert scoring
question-level LLM gate
BoN / PRM@N evaluation
```

Current stage:

```text
two real non-OpenAI experts are integrated:
1. open_math_prm via Skywork-o1-Open-PRM-Qwen-2.5-1.5B
2. open_reasoning_rm via Skywork-Reward-V2-Qwen3-1.7B
```

Next stage:

```text
create a harder or larger candidate set, then train/calibrate the gate
over heterogeneous expert scores.
```

## Main Claim Boundary

Safe current claim:

> We have implemented a reproducible MoPRM pipeline and an OpenAI multi-rubric baseline.

Final claim, only after heterogeneous experts are integrated:

> MoPRM can exploit specialization among heterogeneous PRM/reward experts through routing, improving or matching Best-of-N selection while exposing accuracy-cost tradeoffs.

Claim to avoid:

> Four OpenAI rubric scores alone constitute a full MoPRM expert pool.
